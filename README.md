# 找茬 · zhaocha

### 专治 AI 只会夸你

一个提示词技能：你问"我打算……你觉得怎么样？"，它**不先夸你**，直接挑问题。

**它不提升 AI 的智商，它提升 AI 的「纪律」：**

- **逼它去查** —— 涉及事实 / 数字 / 年份 / 案例 → 先核实，标**来源 + 置信度**；查不到就标"未核实"
- **标不确定** —— **"我没查到" ≠ "不存在"**（搜索无果 ≠ 否证）；核不了绝不当事实讲
- **附检索范围** —— 输出末尾交代"**查了啥 / 没查啥**"；审"状态 / 事实"前先列**覆盖清单**
- **挖隐含假设** —— 固定四块：致命问题 / 隐含假设 / 反例 / 盲点 + 验证动作
- **独立审查** —— 能派子 agent 就派（优先换个模型），**不自己审自己**

## 30 秒用上（不用安装）

1. 打开 [`粘贴版-prompt.md`](粘贴版-prompt.md)；
2. 把里面那段提示词**整段复制**；
3. 粘进**任意 AI**（豆包 / ChatGPT / Kimi / …），再问它你的问题。

## 装进 opencode（进阶）

1. 把 `找茬skill` 文件夹复制到 `~/.config/opencode/skills/`，**目录名改 ASCII**（如 `zhaocha`）；
2. 重启 opencode；
3. 说"帮我找茬：〔你的想法〕"即可。

## 配置（可选）

改 `config.md`（力度 / 风格 / 玩梗程度 / 自质疑力度 / 独立审查 / 检索范围回执…）。默认即可用。

## 边界（诚实说）

- **不适用**：求安慰、要鼓励、纯闲聊（它不负责哄你）；
- **它不保证更准**：实测里它对"静态常识题"没有增量——它的价值是 **纪律 / 多审一遍 / 独立审查**，不是"更聪明"；
- **不是护城河**：一套提示词，**抄走就能用**；
- **它的结论要你复核**：尤其事实 / 法条 / 数字（**它会自信地错**）。
