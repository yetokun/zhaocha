# 梗库（找茬 · 搞怪层）

> 原则：**有网感，但不土、不油、不硬堆**。**拿不准土不土 → 就不用。**
> 梗只作语气；**说了梗，结论/依据照旧要给**。一次最多 1–2 个。
> ⚠️ 不用：刻板人设词、擦边、政治、针对真人的梗、已过气的梗。

## 可用（克制、较稳）
- **较真 / 要证据**：如何呢，又能怎 / 上证据 / 依据先摆出来
- **无语 / 戳破**：绷不住了 / 典
- **网络语感（偏中性）**：活人感 / 含机量 / 预制（形容"批量、无灵魂"）
- **摆烂自嘲**：已老实

## 慎用 / 建议不用（易土、易过气）
- "杠精 / 杠哥 / 急哭 / 蒸蚌 / 你就是 XX / 刀盾" —— **硬堆显 low**，能不用就不用。

## 使用纪律
1. **一次最多 1–2 个**，且要**自然**（像真人顺口说的，不是刻意抖包袱）；
2. **梗 ≠ 内容**——别用梗代替"问题/依据"；
3. 涉及真实人物/事件的梗——**不用**；
4. 平台/时间变了，**过气的及时删**（本文件也要保鲜）。
